# Prompts — histórico de versões

| Versão | Data | Arquivo | Mudança principal |
|---|---|---|---|
| v1 | 15/10/2026 | `v1-classificacao-tipo.md` | classificação por formato (`PDFs`, `Planilhas`...) |
| v2 | 27/10/2026 | `v2-classificacao-conteudo.md` | classificação por assunto, regra de texto curto (0,85), lista fechada e mascaramento |
| chat v1 | 27/10/2026 | `v1-chat-sistema.md` | 11 tools, confirmação `s/n`, conteúdo não confiável |
| chat v2 | 14/11/2026 | `v2-chat-sistema.md` | caminhos relativos a `organizados/`, geração real de `.pdf`, extensões de escrita |

A versão vigente é sempre a de maior número; o código-fonte é a fonte da
verdade (`src/classificador.py`, `src/chat.py`). Nenhum prompt contém chave,
caminho absoluto da máquina ou dado real de pessoa.
